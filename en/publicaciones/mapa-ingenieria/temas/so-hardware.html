    The operating system and the hardware

    With the FIFO algorithm, giving a program more memory can make it fault more. This is Belady’s anomaly, and it shows up with twelve references.

    Privilege modes Interrupts and DMA Virtual memory TLB Page replacement

    01A general-purpose operating system

    A real-time operating system promises deadlines. A general-purpose one, such as Linux, Windows or macOS, promises other things: that many programs share the machine fairly, that none can harm the others or the system, and that each sees more memory than there is. Keeping those promises is not possible with software alone: it needs processor mechanisms. The general concepts of the operating system were covered in operating systems, in Computer Science.

    System promiseHardware mechanism
    Isolation between programs and from the kernelPrivilege modes: user code cannot execute privileged instructions or touch the hardware
    Sharing of the processorA timer that interrupts and returns control to the scheduler
    Private memory for each processThe memory management unit (MMU) translates virtual addresses to physical ones
    Efficient input and outputPeripheral interrupts and DMA

    02Modes, system calls and interrupts

    The processor has at least two modes. In user mode, a privileged instruction or an access to a protected page causes an exception that passes control to the kernel. A program requests services from the kernel with a system call, a special instruction that changes mode and jumps to a fixed address. Peripherals signal with interrupts: the processor saves its state, runs the driver routine and returns. For large transfers, the DMA copies the data between the peripheral and memory and interrupts only when it finishes. Peripheral registers appear as memory addresses, which the kernel maps and protects.

    03Virtual memory

    Each process sees its own address space, divided into pages, typically 4 KB. The MMU translates each address with the process’s page table, which says in which frame of physical memory each page is, with what permissions, or whether it is not loaded. Since reading the table on every access would double the time, the MMU keeps recent translations in a cache, the TLB. If the page is not in memory, a page fault occurs: the kernel brings it from disk, which costs about 80,000 times a memory access (8 ms against 100 ns). Physical memories were covered in electronic memories.

    \[ t_{ef} = h\,(t_{TLB} + t_m) + (1 - h)(t_{TLB} + 2 t_m) \] \[ t'_{ef} = (1 - p)\, t_{ef} + p\, t_{fp} \] \( h \) is the TLB hit rate, \( t_m \) the memory access time, \( p \) the page fault probability and \( t_{fp} \) the time to service it. With 100 ns memory, a 98% hit rate and an 8 ms fault, one fault per 100,000 accesses is enough to almost double the effective time: from 102 to 182 ns.

    04Which page to evict

    When memory is full and a fault occurs, the system has to choose a page to evict. The optimal algorithm, by Belady, evicts the one that will be used furthest in the future: it cannot be implemented because it requires knowing the future, but it serves as a reference. FIFO evicts the oldest; LRU the one least recently used, and it takes advantage of the locality of programs, which tend to return to what they just used. Real systems approximate LRU with a reference bit set by the MMU, in the clock algorithm.

    The Belady sequence shows a surprise: with FIFO, adding a frame can increase the faults. LRU and the optimal algorithm do not have that anomaly. With a loop only slightly larger than memory, LRU and FIFO fault on every reference.

    06Common mistakes

    • Believing that virtual memory is only for having more memory. Its main function is to isolate processes.
    • Ignoring the cost of a page fault. One fault per hundred thousand accesses already almost doubles the effective time.
    • Thinking that more memory always reduces faults. With FIFO that may not be so.
    • Accessing the hardware from a user program. It is done with a driver in the kernel or by mapping memory with permissions.

    07Self-assessment

    How many entries does the page table of a 4 GB address space with 4 KB pages have, in a single level?

    \( 2^{32}/2^{12} = 2^{20} \), one million.

    With 100 ns memory and a 95% TLB hit rate, with no page faults, what is the effective time?

    \( 0.95 \cdot 100 + 0.05 \cdot 200 = 105 \) ns, neglecting the TLB.

    What is Belady’s anomaly?

    That with FIFO, more memory frames can produce more page faults.

    Which processor mechanism prevents a user program from disabling interrupts?

    Privilege modes: that instruction executes only in kernel mode.
